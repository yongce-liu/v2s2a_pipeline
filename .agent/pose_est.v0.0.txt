  ● 这个项目是 基于 FoundationPose 的 6D 物体位姿估计与跟踪 stage,属于          
    v2s2a_pipeline 流水线的其中一环。                                           
                                                                                
    在干什么                                                                    
                                                                                
    它封装了 vendored 的 pkgs/FoundationPose（不改上游代码）:                   
                                                                                
    - 输入(来自前面的 stage):                                                   
      - process/frames.json — 视频帧清单                                        
      - segment/masks.json — 物体分割 mask（初始注册用）                        
      - geometry/geometry.json — 每帧深度 + 相机内参（pointmap Z 通道转 metric  
        depth)                                                                  
      - obj_recon 产出的物体 .obj mesh                                          
    - 过程：在 --init-frame 参考帧上跑完整 pose                                 
  registration(est.register)，之后逐                                            
      帧跟踪（est.track_one)，网络每次运行只加载一次。--reinit-every N 可每 N   
      帧重注册防漂移。                                                          
    - 输出 outputs/<clip>/pose_estimation/:                                     
      - config.json — 有效运行配置                                              
      - poses.json — 每帧位姿清单（index / pose_filename / method)              
      - poses/000000.txt ... — 每帧 4x4 物体-相机位姿矩阵（ob_in_cam)           
                                                                                
    怎么调用                                                                    
                                                                                
    cd pose_estimation                                                          
    uv sync   # 装依赖；pytorch3d/nvdiffrast 用预编译 cu128 wheel，自动装       
                                                                                
    一次性准备（uv sync 搞不定的部分）:                                         
    1. 权重：放                                                                 
       weights/foundationpose/{2023-10-28-18-33-37,2024-01-11-20-02-45}/，并由  
       pkgs/FoundationPose/weights symlink 指过去。                             
    2. mycpp C++ 扩展(mycpp 是 FoundationPose 的 pose clustering pybind11       
       模块，需要 cmake/boost/eigen3):                                          
                                                                                
    cd pkgs/FoundationPose/mycpp && mkdir -p build && cd build                  
    env PATH=/mnt/workspace/miniforge3/envs/daid-foundationpose/bin:$PATH \     
      cmake ..                                                                  
    -DPYTHON_EXECUTABLE=$(pwd)/../../../pose_estimation/.venv/bin/python \      
        -DCMAKE_PREFIX_PATH=/mnt/workspace/miniforge3/envs/daid-foundationpose  
    make -j                                                                     
                                                                                
    运行（以 yellow_spoon 为例）:                                               
                                                                                
    uv run python -m pose_estimation.cli \                                      
      --frames-json outputs/yellow_spoon/process/frames.json \                  
      --masks-json outputs/yellow_spoon/segment/masks.json \                    
      --mesh-path outputs/yellow_spoon/obj_recon/yellow_spoon.obj \             
      --init-frame 0                                                            
                                                                                
    常用参数：--geometry-json（默认自动定位）、--reinit-every N、--max-frames   
    N（冒烟测试）、--foundationpose.est-refine-iter / track-refine-iter（默认   
    5/2)、--output-root。                                                       
                                                                                
    下游 stage 直接读 poses.json + poses/*.txt 即可，不用自己推导路径。
