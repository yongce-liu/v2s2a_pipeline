  来稳定区分左右手。

  它实际用了两套机制：

  1. SAM3 mask 阶段
     - 每次只处理用户指定的一只 anchor hand
     - 例如只输入 "left hand"
     - 在一个参考帧上初始化
     - 使用 SAM3 Video Predictor 向前、向后传播 mask
     - 因此稳定性主要来自视频时序跟踪，而不是左右手文本理解

     - 来自 HaWoR 的手部检测器 weights/hawor/external/detector.pt
     - 检测器类别直接区分：
       - class 0：left hand
       - class 1：right hand
     - 这比让 SAM3 理解 "left" / "right" 可靠得多

  SAM3("left hand")
  SAM3("right hand")

  本身就容易出现两边得到相同 mask、左右互换以及逐帧跳变。

  适合当前项目的改法是：

  - 使用 HaWoR detector 提供左右手框和 handedness
  - SAM3 负责生成精细 hand mask
  - 根据检测框与 SAM3 instances 的重叠关系，把 mask 分配给 left/right
  - 再使用 SAM3 video propagation 保持跨帧身份稳定
  - "yellow spoon" 等普通物体仍使用文本 prompt
  - 最终 JSON 和 overlay 格式保持现在的多 prompt 结构

  API，然后会按这个方向修改，而不是继续依赖 "left hand" / "right hand"
  的文本识别。

  --video.hand-anchor-type box

  使用 HaWoR 的检测框，通常更稳定、边界更准确。

  --video.hand-anchor-type point

  使用检测框中心作为正 anchor 点，可能保留更多手臂区域，但更容易扩张到附近物体。

  默认推荐 box。

  普通 text prompt

  其他对象仍通过：

  --video.sam-mask.text-prompts "yellow spoon"

  进行文本分割。

  推荐命令

  segment/.venv/bin/python -m segment.cli \
    --command video \
    --video.frames-json outputs/yellow_spoon/process/frames.json \
    --video.hand-recon outputs/yellow_spoon/hand_recon \
    --video.hand-anchor-type box \
    --video.hand-sides left right \
    --video.sam-mask.checkpoint weights/sam3/sam3.pt \
    --video.sam-mask.text-prompts "yellow spoon" \
    --video.vis

  输入含义更加明确：

  - left hand：HaWoR box anchor
  - right hand：HaWoR box anchor
  - yellow spoon：SAM3 text prompt

  --video.hand-sides 默认就是：

  left right

  如果只需要一只手：

  --video.hand-sides left

  输出

  outputs/yellow_spoon/segment/
  ├── masks/
  │   ├── 000000.png
  │   ├── left hand/
  │   │   └── 000000.png

  │   └── yellow spoon/
